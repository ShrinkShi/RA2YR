# 开发过程记录

本目录用于记录当前项目开发过程中的关键节点、技术决策、问题排查、变更内容、复盘经验和后续待办。

## 记录目标

- 方便开发完成后复盘
- 方便写 README、release 和技术文档
- 方便后续接手或恢复上下文
- 减少重复踩坑

## 文件说明

| 文件 | 用途 |
|---|---|
| `timeline.md` | 时间线，记录每轮关键开发过程 |
| `decisions.md` | 技术决策，记录为什么这么做 |
| `issues.md` | 问题排查，记录现象、根因和解决方案 |
| `changes.md` | 变更记录，记录本轮实际改动 |
| `lessons.md` | 经验总结，沉淀可复用经验 |
| `backlog.md` | 后续待办，记录未完成事项 |

## 记录原则

只记录有复盘价值的信息，不记录聊天全文、版权素材正文、密钥、密码、令牌、Cookie 或其他敏感信息，不把猜测写成事实。
