# 经验总结

## 2026-08-01 - 版权内容与源码使用文件系统边界隔离

### 场景
兼容引擎需要读取本地版权内容，但开源仓库不得包含这些文件。

### 经验
应先把正式 Git 根限制在源码工程，再使用忽略规则和版权扫描作为第二、第三层防护。

### 下次建议
任何暂存或提交前先验证 Git 顶级目录、候选文件和忽略结果。

## 2026-08-01 - 进程退出码不能代替测试证据

### 场景
Unity 带 `-quit` 返回 0，但没有执行测试或生成 XML。

### 经验
测试入口必须验证本次运行生成的隔离结果文件、实际执行数量和失败数；进程退出 0 只是附加信号。

### 下次建议
所有命令行测试器都应拒绝陈旧、缺失、空白和零测试结果，并为超时或强制收尾保留明确诊断。
