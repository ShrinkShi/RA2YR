# M5-C3 production and technology foundation

M5-C3 adds bounded raw production definitions, explicit availability
evaluation, and deterministic FIFO queue candidates. Raw prerequisite tokens,
TechLevel, BuildLimit, cost, and build-time fields remain preserved; the
availability profile is explicit and reports all blockers without repairing
authored syntax or inferring captured/allied/power behavior.

Queue acceptance, progress, payment, completion, placement, and actor creation
remain separate. The synthetic queue clamps progress only to its declared
expected endpoint after checked addition; it does not mutate C1 credits or
create a unit/building. No UI/sidebar, renderer, campaign trigger, networking,
ProjectBaseline packed data, or original-runtime production claim is included.
