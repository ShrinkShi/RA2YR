## Priority definitions

- **P0** — blocks a trustworthy stock-compatible semantic model or risks destructive roundtrip.
- **P1** — blocks a complete adapter or important version profile.
- **P2** — useful refinement, extension, or tooling behavior.

No question is answered by source voting or visual similarity.

## Evidence plan

For each P0 question, preferred resolution order:

1. original runtime source if ever legally/publicly available;
2. official executable behavior through a separately approved black-box test plan;
3. official editor source for authoring behavior only;
4. two genuinely independent implementations with lineage review;
5. fixed community documentation;
6. future sanitized ProjectBaseline observation;
7. explicit conservative project policy.

No lower grade is relabeled as a higher grade.

## Compatibility gate

Before any compatibility status change, require:

- implemented raw-preserving parser;
- explicit policy configuration;
- synthetic test matrix passing;
- input-mode equivalence;
- license/source review;
- sanitized audit where approved;
- executable acceptance evidence where legal and necessary;
- separate reviewed compatibility update.

This research PR itself satisfies none of those implementation gates and makes no compatibility claim.
